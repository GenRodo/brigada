# Brigada

Herramientas digitales para restaurantes.

Sitio: https://genrodo.github.io/brigada/

## Archivos

- `index.html`: sitio de Brigada (productos, cómo funciona, preguntas frecuentes y contacto).
- `carta.html`: demo de La Carta (menú, tragos, promociones, reseñas, reserva, historia y código QR). Tiene 3 estilos de carta.
- `trabajadores.html`: demo del Portal de trabajadores (sesiones de administrador, supervisor y trabajador).
- `horarios.html`: demo de Horarios para supervisión (creación de horario, anticipos, vacaciones y días/horas trabajadas).

Cada demo tiene su menú de ajustes (engranaje). Los datos de la demo se guardan en el navegador.

PIN de ejemplo del portal: administrador 1111, supervisor 2222, trabajadores 1001 a 1008.
